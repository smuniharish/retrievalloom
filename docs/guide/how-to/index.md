# How-to guides

Solve one production task at a time, with complete code you can copy. Each
guide assumes you have run the
[Quickstart](../../getting-started/quickstart.md); the
[Concepts](../concepts/index.md) pages explain the ideas behind them.

| Guide | Task |
| --- | --- |
| [Use your own embedding model](embedding-model.md) | Add semantic search with any embedding model |
| [Rerank and verify with NLI](rerank-and-nli.md) | Improve ranking with a reranker and check claims with an NLI model |
| [Keep data on disk](durable-storage.md) | Keep documents and indexes across restarts |
| [Run several engines on one store](multiple-engines.md) | Serve one corpus from several processes or hosts |
| [Filter and authorize](filters-and-access.md) | Restrict results by metadata and by who is asking |
| [Backfill and rebuild](backfill-and-rebuild.md) | Add a search method to existing data, or change a model |
| [Write your own backend](custom-backends.md) | Connect your own store or index and test it |
| [Keep the event loop responsive](event-loop-latency.md) | Avoid latency spikes under load |
